---
title: AI 助手
description: 向仪表盘提问，每个数字都有出处，以及配置背后的模型。
---

顶栏的 **AI 助手**根据你能打开的仪表盘回答问题。所有角色都能使用，每个人只能看到自己在当前工作空间的对话。

## 提问

输入问题后按 Enter 发送，Shift+Enter 换行。回答逐字显示，可以停止。关闭或离开页面也会停止回答。

助手的工作方式和你在仪表盘上操作一样：先看有哪些仪表盘，上面有哪些图表和筛选器，再按你要的条件读取图表数据。它可以切换维度和指标、下钻，也能使用图表联动。

它只读取你能看到的内容，并遵守你的[数据权限](/zh-cn/admin/data-permissions/)。它不直接查询数据集，也不写 SQL。

## 出处

回答里的每个数字都来自工具返回的结果，并标明出处，比如 **[1]**。回答下方的**出处**列出每条的仪表盘、图表和条件，点击**打开**按这些条件打开仪表盘。

图表上没有的差值、占比或增长率，用计算器算出来，不靠模型心算，表达式和用到的数字也会列为出处。

对话接近模型的上下文长度时，较早的内容会自动总结。你看到的仍然是完整的对话。

## 图表

图比文字更清楚时，比如几个月的趋势、排名或各部分的占比，助手会在回答里画一张图。画不画、画哪种由它自己判断：折线图、面积图、柱状图、条形图、组合图、饼图或漏斗图。

图只画这条回答查到的数据，和正文里的数字出自同一批行，图下方的**数据出处**列出它们。一张图可以放进两次查询，比如分别查到的华东和华南；也可以逐行算出一个系列，比如每个月的同比增长率，这样的系列连同算式列为出处。

鼠标悬停在图上可以看数值，点击没有反应：要下钻或筛选，就打开出处到仪表盘上看。一次查询超过 200 行时，图上只有助手读到的前 200 行，并会注明。

## 配置模型

只有系统管理员可以配置，在**系统管理 → AI 模型**里。修改立即生效，不用重启。

1. **添加供应商**：填写名称、**协议**、**接口地址**和 **API 密钥**。目前支持 OpenAI 兼容的接口，包括 DeepSeek、通义千问、Kimi、智谱，以及用 vLLM 或 Ollama 部署的模型。密钥加密保存。
2. 为供应商**添加模型**：

   | 字段 | 含义 |
   |---|---|
   | **模型 ID** | 调用接口时传的名称，比如 `deepseek-chat` |
   | **上下文长度** | 单次调用最多能读写多少 token，比如 128K、1M。它决定对话何时总结 |
   | **最大输出** | 一次回答最多多少 token，比如 8K |
   | **思考等级** | 可选，作为 `reasoning_effort` 原样发送。供应商不支持时留空 |
   | **币种** | 价格使用的币种 |
   | **输入**、**缓存命中的输入**、**缓存写入**、**输出** | 每百万 token 的价格。供应商不单独计费缓存时留空 |

3. **测试**发起一次试调用，并检查模型是否会调用工具。不会调用工具的模型无法查数。测试也计入用量。
4. 在**模型用途**里为**对话**选择模型，这是必填项，**标题生成**和**上下文压缩**可选。后两者可以用便宜些的模型，不设置时使用对话模型。

用户不能自己选择模型。正在使用的模型不能删除，要先替换。

部署在反向代理后面时，见[让回答流式显示](/zh-cn/deployment/operations/#反向代理)。

## 用量和花费

系统管理里的 **AI 用量**显示每次模型调用的 token 数和按当时价格算出的花费，可以**按人**、**按模型**、**按工作空间**、**按用途**或**按天**查看。不同币种分开统计，不相加。

管理员看不到对话的内容。
