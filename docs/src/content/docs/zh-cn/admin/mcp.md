SupaBI 提供一个 MCP 地址。把你自己的 AI 客户端（如 Claude、ChatGPT、Claude Code、Cursor）接上来，客户端就能以你的身份读取你能打开的仪表盘。它用的是和 [AI 助手](/zh-cn/admin/ai-assistant/)相同的四个工具：列出仪表盘、查看仪表盘、查筛选器的取值、读取图表数据。

## 开启

系统管理员在 **系统管理 → 通用设置** 的 **MCP 服务** 分组里，给 **MCP 客户端** 勾选 **允许** 并保存之前，MCP 是关闭的。

默认关闭，是因为数据会发给你的客户端所用的模型，这个模型不是管理员选的；而 AI 助手只用在 [AI 模型](/zh-cn/admin/ai-assistant/#配置模型)里配置的模型。关闭后所有客户端立即停用，授权仍然保留，重新打开后照常可用。

## 连接客户端

1. 从账户菜单打开 **个人设置 → MCP**，复制 **MCP 地址**。它以 `/mcp` 结尾，例如 `https://bi.example.com/mcp`。
2. 在客户端里添加一个远程 MCP 服务器（Streamable HTTP），填上这个地址。以 Claude Code 为例：

   ```bash
   claude mcp add --transport http supabi https://bi.example.com/mcp
   ```

3. 客户端会在浏览器里打开 SupaBI。需要时先登录，确认客户端的名称和结果交给谁，然后点 **允许**。

不用复制令牌：客户端通过 OAuth 登录，并自己续期。客户端闲置超过通用设置里的 **登录会话有效期**（默认 7 天）就要重新允许。

页面上会显示当前登录的是谁、结果交给谁。客户端的名称是注册它的人自己起的，只有在你刚刚亲自连接它时才允许。

## 客户端能读到什么

- 一个授权覆盖你所在的所有工作空间。客户端会列出所有这些空间的仪表盘，每个仪表盘都在它自己的空间里读取，用那个空间的时区和你在那里的[数据权限](/zh-cn/admin/data-permissions/)。
- 它只能读到你在 SupaBI 里能看到的，不能改任何东西，也不能直接查数据集或写 SQL。
- 每张图表最多返回 200 行，和 AI 助手一样。图表的 **允许导出数据** 开关对它不起作用，因为它拿不到图表显示以外的数据。
- 每张图表的数据都带出处：仪表盘、图表、生效的条件，以及一个按这些条件打开仪表盘的链接，条件保存 30 天。SupaBI 会要求客户端引用这些出处，但管不了它怎么写回答。

## 客户端从哪里连接

在你电脑上运行的客户端（如 Claude Code、Cursor、VS Code）从你的电脑连接；Claude 网页版和桌面版的连接器、ChatGPT 从各自供应商的云端连接。所以只在公司内网能访问的 SupaBI，只能用在你电脑上运行的客户端。

## 撤销客户端

**个人设置 → MCP** 列出你允许过的客户端，包括它的回调地址、允许时间和最近使用时间。点 **撤销** 立即停用。

管理员停用账号或重置密码时，这个人的客户端也会一并撤销。允许和撤销客户端记在[审计日志](/zh-cn/admin/system/#审计日志)的 **登录** 类里；每次取数记在 **查询** 类里，注明来自 MCP 和哪个客户端。
