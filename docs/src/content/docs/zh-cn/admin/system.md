---
title: 系统管理
description: 账号、用户组、工作空间、审计日志，以及整个组织的设置。
---

**系统管理**在头像菜单里，只有系统管理员能看到，不依赖当前工作空间。

## 用户管理

**添加用户**用初始密码创建账号。创建账号并不会把它加入工作空间，接下来要[把它加为成员](/zh-cn/admin/members/#让用户进入工作空间)。

账号的 **…** 菜单里有：

- **重置密码**，这是忘记密码后唯一的办法。
- **停用**，让账号不能登录。账号只能停用，不能删除。
- **设为系统管理员**和**取消系统管理员**。系统管理员可以管理用户、用户组和所有工作空间，并在每个工作空间都是管理员。

## 用户组

**新建用户组**创建用户组并选择成员，见[用户组](/zh-cn/admin/members/#用户组)。

## 工作空间

**工作空间**列出所有工作空间。**新建工作空间**创建一个，**管理**打开它的设置。

只有系统管理员能删除工作空间，分两步：

1. **删除**让工作空间对所有人隐藏，它留在这个列表里并显示永久删除的日期。进行中的导出会被取消，它的分享链接显示没有权限。在此期间，**还原**可以让它恢复原样。
2. 保留期结束后（默认 30 天），工作空间及其中的全部内容在一小时内被永久删除。**立即删除**马上执行。

账号和用户组属于组织，不会被删除。审计事件保留。永久删除之前，已删除工作空间的名称不能再次使用。

## 审计日志

**审计日志**记录谁在什么时候做了什么，以及读取了哪些数据。可以按时间、工作空间、操作人、类别和结果筛选，打开事件可以看到详情。查询事件包含每条语句的 SQL 和参数。

| 类别 | 记录内容 |
|---|---|
| **登录** | 登录和退出、登录失败及原因、修改密码、允许和撤销 [MCP 客户端](/zh-cn/admin/mcp/) |
| **账号与用户组** | 创建和修改账号、用户组 |
| **工作空间与成员** | 空间设置、删除和成员变化 |
| **授权与数据权限** | 仪表盘授权、数据权限、用户属性 |
| **资源** | 创建、修改和删除数据源、数据集、图表、仪表盘和文件夹，以及带条件的分享 |
| **查询** | 每次从数据源取数 |
| **导出** | 创建、完成、取消和下载 |
| **AI 模型** | 修改 AI 配置 |
| **系统** | 修改通用设置 |

打开列表或编辑器这样的只读操作不记录。每个事件还会写一行带 `msg=audit` 的应用日志，可以由日志系统收集。这行日志不含 SQL、参数和请求内容。

## 通用设置

**通用设置**里是全组织只有一份的设置。各实例每次用到时读取，所以修改立即生效，不用重启。留空时使用默认值。

| 分组 | 设置 | 默认值 | 说明 |
|---|---|---|---|
| **导出** | **导出行数上限** | 2,000,000 | |
| | **导出文件大小上限** | 512 MB | |
| | **导出超时** | 15 分钟 | |
| | **导出文件保留** | 24 小时 | 任务记录保留 30 天 |
| **审计** | **审计保留** | 180 天 | `0` 表示永久保留。AI 用量记录也按这个期限 |
| **查询** | **查询超时** | 60 秒 | 调大时，反向代理的超时可能也要调大 |
| | **默认返回行数** | 1,000 | 图表没有设置行数时读取的行数 |
| | **返回行数上限** | 10,000 | 最大 100,000。数据都在内存里，调大要谨慎 |
| | **缓存默认有效期** | 10 分钟 | 数据源可以单独设置 |
| **工作空间** | **已删除工作空间保留** | 30 天 | |
| **登录** | **登录会话有效期** | 168 小时 | 超过这个时长没有活动就退出登录。[MCP 客户端](/zh-cn/admin/mcp/)闲置这么久也要重新允许 |
| **AI 助手** | **上下文压缩阈值** | 80% | 占模型上下文的比例，50 到 95。超过它，下一次回答前先总结较早的对话，一条回答之内也不再查数据 |
| | **每个回答的工具调用上限** | 60 | 查数、计算、画图都算在内。`0` 表示不限制。每次调用都要把整段对话重新发给模型，次数越多花费越多 |
| **MCP 服务** | **MCP 客户端** | 关闭 | 允许用户连接自己的 AI 客户端，见 [MCP](/zh-cn/admin/mcp/) |

调短保留期时会先要求确认，因为超过新期限的内容会在一小时内删除。

属于每个实例的设置，见[配置](/zh-cn/deployment/configuration/)。
