---
title: 搭建仪表盘
description: 在仪表盘上排列图表、标题、文本、标签页和多个页面。
---

仪表盘把图表排在一页上。到**工作台 → 仪表盘**点击**新建仪表盘**。数据开发和管理员可以创建和修改仪表盘。

仪表盘引用已保存的图表，并不保存副本，所以修改一张图表，所有用到它的仪表盘都会跟着变。

顶栏有名称、撤销和重做、**页面设置**、**预览**和**保存**。左侧工具栏有**图表**、**标题**、**文本**、**标签页**、**全局筛选**和**图表联动**。筛选和联动有单独的一页：[筛选、联动与下钻](/zh-cn/dashboards/interaction/)。

## 添加图表

在**图表**面板里点击图表旁边的 **+**，或者把它拖到画布上。拖动组件的标题栏可以移动，拖动右下角可以调整大小。点击名称旁边的铅笔可以重命名仪表盘。

点击组件会选中它，右上角的 **…** 里是它的操作。最多可以撤销 100 步，Ctrl/⌘+Z 撤销，Ctrl/⌘+Shift+Z 重做。

## 标题和文本

查看时仪表盘不一定显示名称。**标题**用来加一个：默认显示仪表盘的名称和描述，并在改名时跟随变化，也可以自己写标题和副标题。

**文本**用 Markdown 写说明、口径和结论，支持列表、表格和链接。其中的 HTML 按文本显示，链接只能是 http、https 或 mailto，图片不显示。

标题和文本不取数，也不参与筛选和图表联动。

## 组件外观

每个组件都是一个容器。在**外观**里可以设置：

- **背景**：浅灰、配色中的 8 种颜色之一，或者**自定义颜色**，亮色和暗色主题各设一个。
- **透明度**、**显示边框**和**内边距**。

没有单独设置的图表和文本，跟随**页面设置**里的**组件默认外观**。标题可以左中右、上中下对齐。

图表容器还可以有只在这个仪表盘上使用的**显示名称**、以问号显示在标题栏的**备注**，以及查看时**隐藏标题栏**。

## 空容器

图表库顶部的**空图表容器**让你先排版面，之后再放图表。把图表拖到容器上就放进去了；容器里已有图表时，确认后替换。**移出图表**把容器重新清空。

## 标签页容器

标签页容器在一个位置放多张图表，查看的人点击标签切换。在图表容器的 **…** 菜单或属性面板里点击**添加标签页**，原来的图表成为第一个标签，筛选映射和图表联动都保留。

- 每个标签有自己的名称和**备注**，分别映射全局筛选、参与图表联动和导出。
- 在标签列表里，星号设置**默认显示**哪个标签。拖动左侧手柄或用方向键可以调整顺序。
- 把图表从图表库拖到标签栏，会在松手的位置新增一个标签。
- 查看时只有当前标签取数，空标签不显示。
- 只剩一个标签时，它会变回普通的图表容器。

## 分页

仪表盘可以分成多个页面。左侧的**标签页**把它分成两页：图表上方的标题、文本和查询容器移到每页都显示的**共用区域**，其余内容放在第一页。

- 点击标签栏右端的 **+** 添加页面，点击设置按钮可以重命名、调整顺序或删除页面。
- 组件 **…** 菜单里的**移到**把它移到其他页面或共用区域，也可以在共用区域和当前页之间直接拖动。
- 全局筛选仍在一个查询容器里。每页只显示和本页或共用区域的图表关联的筛选器，在一页改的值在其他页同样生效。
- 查看时只有打开过的页面才取数。当前页在地址里，形如 `?page=`。
- 只剩一页时，仪表盘恢复为不分页。

## 页面设置

**页面设置**包括：

- **基本信息**：名称和描述。
- **画布布局**：**网格列数**、**每格高度（px）**、格间距和**自动向上补位**。
- **定时刷新**：见[定时刷新](/zh-cn/dashboards/view-and-share/#定时刷新)。
- **组件默认外观**。

## 保存和授权

**预览**按查看时的样子显示仪表盘。**保存**时和其他[保存](/zh-cn/data/datasets/#保存冲突)一样会检查版本。

第一次保存后会出现**授权**。普通用户只能看到授权给他们的仪表盘，所以新仪表盘要选好能看到它的用户、用户组或**全体成员**，他们才看得到。数据开发和管理员能看到所有仪表盘。

在工作台里，仪表盘、图表和数据集各有自己的文件夹，用**新建文件夹**创建，用**移动到…**放入。文件夹只用于整理，不影响权限，文件夹清空后才能删除。
