---
title: 筛选、联动与下钻
description: 让查看的人缩小范围、在图表之间点击联动，以及往下钻取。
---

图表可以有[自己的筛选器](/zh-cn/charts/editor/#筛选器)。在仪表盘上还有三种改变显示内容的方式，查看的人都可以使用。

## 全局筛选

全局筛选同时作用于多张图表，放在仪表盘顶部的查询容器里。

1. 点击编辑器左侧的**全局筛选**，再点击**添加全局筛选器**。
2. 在**关联图表与字段**里勾选要作用的图表，并为每张图表选择字段。相同数据集的相同字段会自动建议，不同数据集要手工映射。
3. 选择条件、控件和**默认值**。日期字段上的全局筛选就是仪表盘的时间范围，各图表可以使用不同的日期字段。
4. **选项来源**决定下拉选项取自哪张图表的字段。

**全局条件会替换图表在同一字段上的筛选器**，包括条件和值。图表自己的控件保留但置灰。全局值为空表示不限制。其他字段上的图表筛选器继续生效。

查看时如果某张图表要退出，可以用**使用图表筛选**，它会忽略全局筛选，恢复图表自己的条件。**恢复全局筛选**可以撤销。这个状态不会保存。

在查询容器的设置里，**触发方式**可选**自动触发**（每次修改立即查询）或**手动触发**（查看的人点击**查询**）。**重置筛选条件**把所有条件恢复为默认值。

**上级筛选器**让全局筛选可以[级联](/zh-cn/charts/editor/#级联筛选)。全局筛选暂时不能关联[参数](/zh-cn/data/parameters/)。

## 图表联动

图表联动让点击一张图表时筛选其他图表。

1. 点击编辑器左侧的**图表联动**，再点击**新增联动**。
2. 在**联动源**里选择**来源图表**和**点击字段**。
3. 在**联动目标**里添加图表，并为每张图表选择**目标字段**。每张目标图表映射一个字段，不同数据集的字段要手工映射。

联动源可以是柱状图、条形图、饼图的类别，聚合表的维度，或者明细表的列。透视表、合计行和“其他”扇区不能作为联动源。

使用时，点击一个值，在菜单里选择**图表联动**。再次点击同一个值时菜单项变为**取消联动**。仪表盘顶部列出**当前联动**，可以逐个取消。联动使用原始值，不是显示出来的文本，多个联动要同时满足。

## 下钻

图表设置了[下钻](/zh-cn/charts/editor/#下钻)时，点击一个值，选择**下钻到**下一层。图表上方会显示当前位置，比如**下钻层级：**大区 › 华东 › 江苏。点击其中一段可以返回。

- 下钻只改变这张图表，不筛选其他图表。
- 筛选、图表联动或动态选择变化时，下钻位置保留，刷新时也一样，所以某一层没有数据时会显示为空。**重置筛选条件**回到第一层。
- 既能下钻又是联动源的图表，只在第一层能联动。
- 放大视图和卡片共用下钻位置，导出的是眼前这一层的数据，分享链接可以带上它。
- 在折线图、面积图和组合图上，点击类别上方的任意位置都算数。

## 条件怎样组合

下面这些条件以“且”的关系一起缩小数据范围：

1. 数据集的 SQL 和[行权限](/zh-cn/admin/data-permissions/)，始终生效。
2. 图表的筛选器，被全局筛选替换的除外。
3. 全局筛选。
4. 图表联动。
5. 下钻。

查看的人只能向作者设置好的筛选、联动和动态字段传值，不能自己写条件。
