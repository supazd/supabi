---
title: 参数
description: 把值传进数据集的 SQL，用于筛选器做不到的情况。
---

参数是写进数据集 SQL 的值。大多数时候并不需要它。

## 筛选器还是参数

只为缩小范围时，把这一列输出，在[图表里用筛选器](/zh-cn/charts/editor/#筛选器)。条件加在数据集 SQL 外层，数据库会把它下推到查询里。只有筛选器做不到时才用参数：

| 情况 | 示例 |
|---|---|
| 同一个值要用在 SQL 的多处 | 两张快照表关联，两边都要 `dt` 等于同一天 |
| 必须有且只有一个值 | 每个 `dt` 都是全量快照的表，选多天会重复计算 |
| 条件必须在聚合之前生效，而这一列没有输出 | 截至某天每个用户的最新一单 |
| 值参与计算 | 截至某个日期的账龄，或者汇率 |

## 写参数

参数在[数据探索](/zh-cn/data/exploration/)里写：

```sql
SELECT id, amount
FROM demo.orders
WHERE status = {{status}}
  [[AND channel = {{channel}}]]
```

- `{{name}}` 是参数。它本身代表一个值，不加引号。名称由小写字母、数字和下划线组成，不能以数字开头。
- `[[ ... ]]` 是可选片段：其中的参数没有值时，整段都会去掉。
- 接受多个值的参数写成 `IN {{name}}`，不加括号。
- 写在字符串或注释里的 `{{name}}` 只是普通文本，不是参数。

参数以绑定值的方式传给数据库，所以只能替换值，不能替换表名或列名。

## 设置参数

SQL 里有参数时，编辑器右侧会出现**参数**，每个参数一项：

| 设置 | 含义 |
|---|---|
| 显示名 | 用户看到的名称，默认用参数名 |
| 类型 | 文本、整数、小数、布尔、日期或时间 |
| **多值** | 这个参数接受多个值 |
| **必填** | 必须有值 |
| 默认值 | 没有传值时使用。日期可以写相对值，比如 `today` 或 `today-1d` |

参数勾选了**必填**，或者写在 `[[ ]]` 外面时，就必须有值。这时如果没有默认值，每次查询都要传值。

这些设置随数据集保存。**生成数据集**和**应用并返回数据集**会把它们和 SQL 一起带上。

## 在图表里使用

数据集的参数列在图表编辑器字段列表的底部。把参数拖到**筛选器**，或者点击它，打开**参数设置**：

- 不勾选**显示为图表筛选器**时，它是固定值，查看的人既看不到也改不了。
- 勾选后，选择**输入**由查看的人填写，或者选择**下拉选择**从你列出的选项里选。选项手工填写，最多 500 个。

默认值跟随数据集，在图表里改过之后才属于图表自己。**恢复为数据集的默认值**可以改回来。

查看的人会在编辑器预览、仪表盘和放大视图的图表上看到这些控件。参数写在 `[[ ]]` 里时，清空控件表示不限制；SQL 离不开它时，控件不能清空。

## 限制

- [全局筛选](/zh-cn/dashboards/interaction/#全局筛选)暂时不能关联参数。
- 分享链接和其他图表筛选一样，会带上参数的值。
- 同比和环比只偏移时间筛选，不偏移参数。参数是业务日期时，本期和对比期读取的是同一天的数据。
