title: 数据集
description: 把查询描述一次，让所有图表读取同样的字段。
---

数据集是一条 SQL 查询，加上对字段的描述。图表读取的是数据集而不是表，所以在数据集上设置的名称、计算和权限，对读取它的每张图表都生效。

新数据集从 SQL 生成：在[数据探索](/zh-cn/data/exploration/)里写一条查询，点击**生成数据集**。数据开发和管理员可以创建和修改数据集。已保存的数据集以只读方式打开，点击**编辑**后才能修改。

## 字段

SupaBI 读取查询返回的列，为每一列建议一个字段。数字列是度量，其他列是维度；名为 `id` 或以 `_id` 结尾的数字列按维度处理。

| 类型 | 含义 | 示例 |
|---|---|---|
| **维度** | 用来分组、筛选和排序的值 | 大区、下单时间 |
| **度量** | 每行上的数字，放到图表上时做聚合 | 订单金额 |
| **指标** | 自身表达式里已经聚合好的数字 | 人均销售额 |

点击**编辑**，再打开**字段详情**，可以调整每个字段：

- **名称**是用户看到的唯一名字，可以随时修改，改名后图表不受影响。
- **描述**用来解释字段，AI 助手也会读取。
- **转为度量**和**转为维度**让数字在两种类型之间切换。文本和日期只能是维度。
- **隐藏**把字段从图表的字段列表中去掉，已经使用它的图表不受影响。这不是权限，限制访问请用[数据权限](/zh-cn/admin/data-permissions/)。
- **复制**为同一列再建一个字段，比如 `用户 ID` 作为维度，它的副本作为度量做去重计数。

## 计算字段

**新建计算字段**添加一个由表达式算出来的字段，而不是从列读取。用 `${名称}` 引用其他字段，点击**试算**可以看到前几行的结果：

```sql
CASE WHEN ${订单金额} >= 1000 THEN '高' WHEN ${订单金额} >= 100 THEN '中' ELSE '低' END
```

**新建指标**添加一个在表达式里自己做聚合的字段。比率、加权平均，以及只有一种正确算法的数字，都应该写成指标，这样每张图表的算法都一样：

```sql
SUM(${订单金额}) / NULLIF(COUNT_DISTINCT(${用户 ID}), 0)
```

图表直接使用指标，不能再次聚合。可以写哪些内容，见[表达式与函数](/zh-cn/data/expressions/)。

## 显示格式

在**字段详情**里，数字和日期字段可以带显示格式，决定它在表格、坐标轴、标签和提示框里怎么写。格式只改变写法，不改变值：筛选、排序和导出仍然使用原始值。图表可以[按列覆盖](/zh-cn/charts/editor/#显示格式和样式)。

数字：

| 选项 | 含义 |
|---|---|
| **样式** | **无**按原样显示。**数值**使用下面的选项。**百分比**把比率写成百分数，0.2345 显示为 23.45% |
| **小数位数** | 固定的小数位数。**自动（最多 2 位）**会去掉末尾的 0 |
| **千分位分隔符** | 分隔符跟随界面语言 |
| **单位** | 先换算再显示：千、万、百万、亿或十亿。**自动**为每个值分别选单位，中文用万和亿，英文用 K、M、B |
| **前缀**、**后缀** | 各不超过 16 个字符，比如 ¥ 或 元 |

单位选万、保留两位小数、前缀 ¥、后缀 元时，1234567.891 显示为 ¥123.46万元。

日期：

| 选项 | 含义 |
|---|---|
| **写法** | **横线**（2026-01-05）、**斜线**（2026/01/05）或**中文**（2026年1月5日） |
| **不分组时的时间** | 未分组的时间写到哪一级：**到秒**、**到分**或**只显示日期** |
| **按周分组时** | **起止日期**、**第一天**或**第几周** |

## SQL 或表发生变化时

要修改 SQL，点击**查看 SQL**，再点**在数据探索中编辑 SQL**。如果表变了而 SQL 没变，点击**同步字段**。两种情况下，SupaBI 都会把字段和查询现在返回的列做比较：

- 新出现的列会得到一个新字段。
- 列已消失的字段会标记为**已不存在**。**指向另一列**可以保留它的名称和所有引用，列被改名时就该这样做。否则就删除这个字段。存在这样的字段时，数据集不能保存。

保存时，SupaBI 会用零行试运行一次查询和表达式，以便发现错误。如果改动影响到图表（比如删除了字段），它会列出这些图表并要求确认。被数据权限规则引用的字段不能删除。

## 修订历史

每次保存都会生成一个版本。在**修订历史**里可以查看每个版本、比较任意两个版本，以及**恢复为草稿**。恢复的内容要再次保存才生效，保存时会和平时一样做校验，并生成新版本。数据权限是分开保存的，不会被恢复。

## 保存冲突

数据集、图表和仪表盘在保存时都会检查版本。如果别人先保存了，你的保存会被拒绝，草稿保留。**查看差异**把**原始内容**、**我的草稿**和**最新保存内容**放在一起显示：

- 互不冲突的改动会自动合并。
- 双方把同一处改得不一样时，由你来选。数据集的名称、显示格式、描述和隐藏状态按属性逐项比较；字段的类型、表达式或列的改动按整个字段处理。

**应用到草稿**只更新你的草稿，检查后再保存一次。

## 谁在读取数据集

**被引用**列出读取数据集的图表和仪表盘。工作台里的**数据血缘**用一张图展示全貌，从数据源和表，经过数据集和图表，一直到仪表盘。打开**只看未被引用的**可以找出能清理的内容。

血缘通过读取 SQL 里 `FROM` 和 `JOIN` 后面的名称来找表，所以它知道数据集读了哪些表，但不知道读了哪些列。
