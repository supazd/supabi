数据源是到一个数据库的连接。它属于某一个工作空间，由数据开发和管理员在**工作台 → 数据源**里管理。

## 支持的数据库

| 类型 | 数据库 | 版本 |
|---|---|---|
| 事务型 | PostgreSQL | |
| 事务型 | MySQL | 8.0 及以上 |
| 分析型 | ClickHouse | |
| 分析型 | Apache Doris | |
| 分析型 | StarRocks | |
| 分析型 | Trino | 418 及以上 |

## 添加数据源

1. 点击**添加数据源**，选择数据库。
2. 填写表单。
3. 点击**测试连接**，显示**连接成功**后点击**保存**。

| 字段 | 适用于 | 含义 |
|---|---|---|
| **名称** | 全部 | 在 SupaBI 里显示的名称 |
| **主机**、**端口** | 全部 | 数据库监听的地址。端口留空时使用该数据库的常用端口 |
| **数据库** | 除 Trino 外 | 要连接的数据库。ClickHouse 上可不填 |
| **默认 catalog**、**默认 schema** | Trino | 表名不带前缀时到哪里查找 |
| **用户名**、**密码** | 全部 | SupaBI 连接时用的账号。密码加密存储，保存后不再显示；编辑数据源时留空则沿用已保存的密码。改了主机、端口、用户名或加密设置之后，要重新输入密码：已保存的密码只会发给保存它时的那台服务器 |
| **SSL 模式** | PostgreSQL | `disable`、`prefer`、`require`、`verify-ca` 或 `verify-full` |
| **TLS** | MySQL、Doris、StarRocks | 连接是否加密 |
| **加密连接** | ClickHouse、Trino | 连接是否加密 |
| **数据时区** | 全部 | 数据库里不带时区的时间实际所在的时区 |
| **结果缓存** | 全部 | 结果保留多久，见下文 |
| **最大并发查询** | 全部 | 同时运行多少条查询，见下文 |

:::caution[请使用只读账号]
SupaBI 只执行读取语句，并在支持只读会话的数据库上使用只读会话。StarRocks 和 Doris 没有只读会话，账号就是唯一的保护。在所有数据库上，数据开发都能读到这个账号能读到的全部数据。
:::

## 查询设置

**结果缓存**决定相同的查询在多长时间内直接使用上次的结果，不再访问数据库：

| 选项 | 含义 |
|---|---|
| **跟随系统默认** | 使用[系统管理](/zh-cn/admin/system/#通用设置)里的缓存默认有效期，默认 10 分钟 |
| **不缓存** | 每次都访问数据库，适合看重实时数据的数据库 |
| **自定义** | 自己设定有效期，1 到 1440 分钟 |

**最大并发查询**限制每个实例同时对这个数据源执行的查询数，范围 1 到 64，其余的排队等待。留空时为 8。每个实例对数据库打开的连接最多比这个数多 2 个，空闲 5 分钟后关闭；调大之前，请确认数据库允许的连接数够每个实例这样用。

## 数据源页面

保存后，页面会显示连接是否正常、各项设置，以及：

- **库表结构**：所有的表和列，带上数据库里的注释。
- **被引用**：读取它的数据集，以及依赖这些数据集的图表和仪表盘。**在血缘图中查看**会用[血缘图](/zh-cn/data/datasets/#谁在读取数据集)展示同样的内容。

**在数据探索中查询**会打开这个数据源上的查询。

## 删除数据源

数据源删除后，读取它的资源都将无法使用，确认时会提示受影响的数量。
