title: 数据探索
description: 对数据源写 SQL，查看结果，并把查询变成数据集。
---

顶栏的**数据探索**是对数据源写 SQL 的地方，数据开发和管理员可以使用。

## 运行查询

在左上角选择数据源，下面会列出它的表，点击表名可以把它放进 SQL。

用数据源自己的语法写一条 `SELECT` 语句，点击**运行**或按 Ctrl+Enter（Mac 上按 ⌘+Enter）。如果选中了一部分 SQL，只运行选中的部分。

编辑器下方的面板有四个标签：

| 标签 | 内容 |
|---|---|
| **结果** | 查询到的行。最多显示 1000 行，用 `WHERE` 缩小范围可以看到其余的行 |
| **列** | 每一列的名称和数据库类型 |
| **执行计划** | 数据库会怎样执行这条 SQL。点击工具栏上的**执行计划**，不会真正运行 |
| **历史** | 运行过的 SQL |

**格式化**用来整理 SQL，**新建查询**再打开一个标签页。

:::note
查询标签页、草稿和历史都保存在当前浏览器里，按账号和工作空间分开，换一个浏览器就看不到了。要长期保留查询，请把它保存成数据集。
:::

## 生成数据集

点击工具栏上的**生成数据集**。数据集会带着当前的 SQL 在新的浏览器标签页中打开，如果浏览器询问，请允许弹出窗口。详见[数据集](/zh-cn/data/datasets/)。

SQL 和[参数](/zh-cn/data/parameters/)属于数据集。之后要修改，打开数据集并选择**在数据探索中编辑 SQL**。**应用并返回数据集**会更新原表单的草稿，保存数据集后才生效。

## 导出结果

**导出 SQL 结果**把完整结果写成 CSV 或 XLSX 文件，不受 1000 行的限制。

1. 点击**导出 SQL 结果**。如果选中了一部分 SQL，只导出选中的部分。
2. 选择**文件格式**和**文件名称**，点击**开始导出**。
3. 可以离开页面。任务在后台运行，文件就绪后顶栏的**导出**按钮会显示标记。

导出会保存一份 SQL 和参数的快照，并在后台重新运行。默认情况下，一次导出最多 200 万行、512 MB、15 分钟，文件保留 24 小时。系统管理员可以在[通用设置](/zh-cn/admin/system/#通用设置)里修改。XLSX 超出一个工作表的容量时会自动拆分，长数字和高精度小数保留为文本。
