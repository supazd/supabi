---
title: 图表编辑器
description: 把字段放到图表上，做筛选和计算，并让查看的人调整图表。
---

图表读取一个[数据集](/zh-cn/data/datasets/)。在数据集上点击**新建图表**，或者到**工作台 → 图表**点击**新建图表**。数据开发和管理员可以创建和修改图表。

左边是数据集的字段，旁边是**图表类型**和样式选项。右边是放字段的行，下面是预览。底部面板有**数据**、**查询诊断**、**查看图表定义**、**被引用**和**修订历史**。

## 把字段放到图表上

把字段从左边拖到某一行，或者点击它加到末尾。有哪些行取决于[图表类型](/zh-cn/charts/types/)：大多数类型有**维度**和**指标**，明细表有**列**，透视表有**行**和**列**。

打开**自动查询**后，每次修改都会更新预览，否则点击**查询**。

在同一行内拖动可以调整顺序，也可以用字段菜单里的**前移**和**后移**。字段有焦点时，Alt+← 和 Alt+→ 也一样。这个顺序就是查询返回的列的顺序。

日期维度按**时间粒度**分组，这一项在各行的下方：年、季度、月、周或日。

点击字段打开菜单：

| 选项 | 含义 |
|---|---|
| **求和**、**平均值**、**最小值**、**最大值**、**计数**、**去重计数** | 度量的聚合方式。文本和日期只有后四种。度量默认求和，拖到**指标**的维度默认去重计数。数据集里的[指标](/zh-cn/data/datasets/#计算字段)不能选择 |
| **添加别名** | 这个字段只在这张图表上用的名称 |
| **升序**、**降序** | 按这一列排序。有多个排序列时，靠前的优先。没有排序时，依次按维度升序 |
| **指标计算** | 见[下文](#指标计算) |
| **钻取设置…** | 见[下文](#下钻) |
| **显示格式…** | 见[下文](#显示格式和样式) |

**通用**里的**最多显示行数**限制图表读取的行数，默认 1000，上限 10000，系统管理员可以[修改这些限制](/zh-cn/admin/system/#通用设置)。按指标排序再限制行数，就是前十名。

## 筛选器

筛选器限制图表读取的行。把字段拖到**筛选器**，打开**筛选器设置**。系统不会替你添加筛选器：数据集没有默认的时间字段，每张图表需要什么筛选就加什么。一张图表上的多个筛选器要同时满足。

- 不勾选**显示为图表筛选器**时，它是固定条件，查看的人既看不到也改不了。
- 勾选后，它会以**显示名**和**控件**出现在图表上方，它的值是默认值。在编辑器预览里试选的值不会改变默认值。

可用的条件和控件取决于字段：

| 字段 | 条件 | 控件 |
|---|---|---|
| 文本、整数、布尔 | 等于任一、不等于任一 | **下拉选择**、**搜索 + 下拉**、**平铺选择** |
| 文本 | 包含、开头是、匹配模式等 | **搜索框** |
| 数字 | 介于、不介于 | **数值范围** |
| 数字 | 等于、大于等 | **数值** |
| 日期、时间 | 时间范围 | **单个日期**、**日历（起止日期）**、**日期范围** |

日期范围可以是**动态日期**（比如最近 30 天）、**固定日期**、**高级**（两端分别可以是固定、动态或无限制），或者**特殊值**（比如**空日期**）。

在模式里，`%` 代表任意长度的文本，`_` 代表一个字符。

**筛选方式**对度量有影响。**明细筛选**在分组之前过滤行；**结果筛选**在分组之后过滤，比如合计不低于 1000 的大区，聚合用你选的**聚合方式**。

### 级联筛选

**上级筛选器**让一个筛选器的选项依赖另一个，比如选了省份之后缩小城市的范围。只有精确选值的筛选器才能级联。

## 指标计算

数字度量菜单里的**指标计算**基于聚合后的值再做计算：

| 选项 | 含义 |
|---|---|
| **原值** | 不计算 |
| **占全部** | 占所有行合计的比例 |
| **组内占比** | 在组内的占比，可以选择分母按哪些维度分组 |
| **同比 / 环比** | 和之前的周期比较 |
| **累计** | 沿一个维度累加 |

**同比 / 环比**要选择**时间字段**和**本期范围**，再选**同比**或**环比**、偏移的周期数和**时间单位**。**计算结果**可以是**同期值**、**差值**或**增长率**。

**累计**要在**沿这个维度累计**里选维度。累计从筛选范围的起点开始，不包含更早的数据，并在其他维度的每个分组内重新开始。它适用于求和、计数、最小值和最大值，不适用于平均值、去重计数和数据集指标。

## 动态维度和动态指标

动态字段让查看的人切换图表的分组或计算内容，不用为每种情况各做一张图表。在字段列表里用**添加动态维度**或**添加动态指标**，填写**显示名称**，再添加**候选字段**。查看的人会在图表上看到控件。

**维度选项可以为空**允许查看的人去掉分组。一张图表最多 16 个动态字段，每个最多 64 个候选字段。明细表不支持。

## 下钻

下钻让查看的人点击一个值，沿你设定的路径往下看一层。在维度菜单里点击**钻取设置…**打开层级设置：第一层是维度本身，**添加下一层**增加一个字段，日期还可以选粒度。

```text
大区 → 省份 → 城市
下单时间按年 → 按季度 → 按月 → 按日
```

- 适用于柱状图、条形图、折线图、面积图、组合图和饼图的类别，以及聚合表的任意维度。
- 一张图表只有一个下钻，算上第一层最多 8 层。
- 日期的每一层都必须完整落在上一层之内，所以周不能排在月后面。
- 层级保存在图表里，不在数据集里。

设置后，维度上会出现**钻取**标记，也可以在编辑器预览里点击试用。见[查看的人怎样使用](/zh-cn/dashboards/interaction/#下钻)。

## 显示格式和样式

**显示格式…**在这张图表上为这一列覆盖[数据集的格式](/zh-cn/data/datasets/#显示格式)。**跟随数据集**和其他样式并列，选它就恢复。

左边的选项取决于图表类型：

| 分组 | 选项 |
|---|---|
| **样式** | 比如**堆叠**、**百分比堆叠**、**平滑曲线**、**显示数据点**、**柱子最大宽度（像素）** |
| **图例与标签** | **图例**位置、**在图上显示数值** |
| **颜色** | **配色方案**和每个指标的颜色。颜色来自 8 种经过挑选、容易区分的色相 |
| **坐标轴** | **标题**、**最小值**、**最大值**、**隐藏网格线**、**隐藏刻度标签**、**标签角度** |

系列或扇区超过 8 个时，保留最大的 7 个，其余合并为“其他”。

## 查询诊断

**查询诊断**显示主查询、合计和小计的 SQL 与绑定参数，以及耗时、缓存状态和结果是否被截断。它只提供给数据开发和管理员，每次查询单独请求。

## 保存

有改动时**保存**才可用。每次保存都会在**修订历史**里加一条，列出版本、时间和修改人。这里不能比较和恢复，因为图表画出来的内容还取决于它的数据集。如果别人先保存了，见[保存冲突](/zh-cn/data/datasets/#保存冲突)。

**通用**里的**允许导出数据**让能打开仪表盘的人[导出这张图表的数据](/zh-cn/dashboards/view-and-share/#导出图表数据)。默认关闭，关闭时任何人都不能从仪表盘导出这张图表。
