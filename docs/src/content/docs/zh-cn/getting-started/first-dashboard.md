---
title: 制作第一个仪表盘
description: 连接数据库，写一条查询，再把它变成数据集、图表和仪表盘。
---

SupaBI 里的一切都从查询开始：连接数据库，写 SQL，保存成数据集，再基于数据集制作图表和仪表盘。

本指南使用[在自己的机器上试用](/zh-cn/getting-started/install/#在自己的机器上试用)载入的示例数据。要用自己的数据库，改掉连接信息和 SQL 即可。你需要数据开发或管理员角色，管理员账号已经具备。

## 添加数据源

1. 在顶栏打开**工作台**，在左侧选择**数据源**。
2. 点击**添加数据源**，选择 **PostgreSQL**。
3. 填写表单：

   | 字段 | 值 |
   |---|---|
   | 名称 | `Sample` |
   | 主机 | `127.0.0.1` |
   | 端口 | `15432` |
   | 数据库 | `supabi` |
   | 用户名 | `supabi_demo` |
   | 密码 | `demo` |
   | 数据时区 | `Asia/Shanghai` |

4. 点击**测试连接**。显示**连接成功**后，点击**保存**。

现在数据源页面会列出它的表。

:::tip
连接自己的数据库时，请使用只读账号。**数据时区**是数据库里不带时区的时间戳所在的时区。
:::

## 写一条查询

1. 在顶栏打开**数据探索**。左侧是数据源里的表。
2. 粘贴下面的 SQL，点击**运行**，或者按 Ctrl+Enter（Mac 上按 ⌘+Enter）：

   ```sql
   SELECT o.created_at, r.name AS region, p.category, o.channel, o.quantity, o.amount
   FROM demo.orders o
   JOIN demo.regions r ON r.id = o.region_id
   JOIN demo.products p ON p.id = o.product_id
   ```

结果显示在编辑器下方，只展示前 1000 行；基于这条查询的图表会读取全部数据。

## 生成数据集

1. 点击工具栏上的**生成数据集**。数据集会在新的浏览器标签页中打开，如果浏览器询问，请允许弹出窗口。
2. 看左侧的**字段大纲**。SupaBI 已经把列分好类：`quantity` 和 `amount` 是度量，图表可以对它们求和；其他列是维度，图表可以按它们分组。
3. 输入名称 `Orders`，点击**保存**。

## 制作图表

1. 点击数据集右上角的**新建图表**。
2. 在**图表类型**下选择**柱状图**。
3. 把 `region` 拖到**维度**，把 `amount` 拖到**指标**。图表立刻出现，`amount` 按 `SUM(amount)` 求和。
4. 输入名称 `Sales by region`，点击**保存**。

## 制作仪表盘

1. 在**工作台**左侧选择**仪表盘**，点击**新建仪表盘**。
2. 在右侧的**图表**面板里，点击 `Sales by region` 旁边的 **+**。
3. 点击名称旁边的铅笔，输入 `Sales overview`，按回车。
4. 点击**保存**。

现在可以在顶栏的**我的仪表盘**里看到这个仪表盘。

## 分享

普通用户只能看到授权给他们的仪表盘，所以新仪表盘要授权后他们才能看到：

1. 在仪表盘编辑器里点击**授权**。这个按钮在仪表盘保存后才出现。
2. 选择能看到它的用户或用户组，或者选择**全体成员**。

要把仪表盘发给别人，在**我的仪表盘**里打开它，点击**分享**并复制链接。链接本身不授予权限，只有能打开这个仪表盘的人才能看到。
